# Run embedded shiny applications

Run embedded shiny applications

## Usage

``` r
run_app(app, launch_browser = TRUE)
```

## Arguments

- app:

  A string representing the name of the application to run

- launch_browser:

  logical. Should the app be launch in the system's default browser?
  (default is TRUE)

## Examples

``` r
run_app("rule_eval")
```
