# Browse Rnssp vignettes

Browse a specified Rnssp vignette, or browse the available ones from the
Rnssp online documentation.

## Usage

``` r
Rnssp_vignettes(topic = NULL)
```

## Arguments

- topic:

  a character string giving the (base) name of the vignette to view. If
  omitted, the webpage with all vignettes from the Rnssp package is
  browsed

## See also

[`browseURL`](https://rdrr.io/r/utils/browseURL.html)

## Examples

``` r
if (FALSE) { # \dontrun{
Rnssp_vignettes()
Rnssp_vignettes(topic = "Rnssp_intro")
} # }
```
